최초 실패와 후속 보완

  1. SDK 개발용 stub 이름을 잘못 분류한 수집 도구의 최초 중단을 보존했습니다.
  2. SDK 헤더 구조와 compiler의 공백 경로 때문에 발생한 빌드 실패를 기록했습니다.
  3. 원본 compiler와 소스를 보존하고 경로 및 연결 설정을 보완해 빌드를 완료했습니다.
  4. 별도 torch-scatter 의존성을 설치한 후 같은 3개 모듈을 새 프로세스에서 다시 검사했습니다.
  5. 빌드한 Warp의 실제 GPU 커널 2개를 CPU 기준과 비교했습니다.
