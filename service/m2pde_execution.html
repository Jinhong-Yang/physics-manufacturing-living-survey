조건주 실행관측과 한계

실패한 9개 주 실행은 같은 사전조건 오류가 반복된 것입니다. 독립적인 예측 실패율로 집계하지 않습니다. 각 조건의 추가 반복도 주 실행 수에서 제외합니다.

저자 requirements는 PyTorch 2.4.0+cu118입니다. Windows DLL 오류는 이번 2.4.0 CPU 이식 환경에서의 관측이며, 저자의 CUDA 환경을 시험한 결과가 아닙니다. 과거 FNO 구현은 이후 저자가 수정한 버그 이전의 소스입니다. 가중치 구조 호환성만으로 학습 소스의 동일성을 증명하지 않습니다.

과거 소스 수정 실행의 수치 비교

이 표는 과거 소스 수정 실행의 출력만 보여줍니다. 별도 구현한 DOP853 수치해를 분모로 한 상대 L2 오차입니다. 생성기와 같은 선언 방정식·경계 차분을 유지한 비교이며, 외부 제조 계측에 의한 검증은 아닙니다. 초기조건별 난수 반복은 서로 독립된 제조 사례가 아닙니다.

초기조건 시드생성 시드u 상대 L2v 상대 L2생성 부분 시간

시간은 CPU 4개 스레드의 생성 부분만 측정하며 import와 모델 로드를 제외합니다. 수치해 풀이 대비 속도 향상이나 공장 처리량으로 해석하지 않습니다.

실행 구성과 적용 조건

20개 공간 격자, 10개 시간점, 250단계 DDPM, 2회 결합 반복과 배치 1을 사용했습니다. u의 누락된 model-100.pt 대신 model.pt를 명시적으로 선택했고, Python 3.12.14와 PyTorch 2.4.1 CPU 환경을 사용했습니다. 원본 소스 파일을 수정하거나 누락 가중치를 임의로 채우지 않았습니다.

새 입력 3개는 제공된 결합 데이터 10,000개 초기조건과 정확히 일치하지 않았습니다. 비공개 학습 입력과의 중복은 판단하지 않습니다. 저장소의 CC BY-NC 조건과 외부 데이터·가중치·출력의 권리 범위도 별도 검토 대상입니다. 원자로·열파이프 실행, 독립 물리 검증과 외부 제조 허용기준은 미완료입니다.
