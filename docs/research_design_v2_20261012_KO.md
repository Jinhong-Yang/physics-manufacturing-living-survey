# 실행 가능한 공개 릴리스에서 제조 사용 판단까지: 상세 연구 설계 v2

2026년 10월 12일 개정. 작업 폴더는 `[비공개 연구 작업 폴더]`이다. 이 문서는 기존 설계의 후속 버전이며, 이전 동결 결과와 실패 기록을 보존한다. 목표 저널은 IEEE Access이며, 현재 산출물은 투고 준비 중인 연구 설계와 초안이다.

## 1. 연구 목적과 기여

가제는 **Public Release to Manufacturing Use: A Living Evidence Survey of Physics-Consistent Synthetic Data Generation**이다. 상위 AI 학회의 연구를 공개 코드·모델의 실제 실행 가능성과 지정 제조 용도에서의 사용 가능성을 중심으로 분석한다. 제공 서비스는 논문 목록에서 코드 링크를 보여주는 수준을 넘어, 특정 릴리스·입력·환경·실행·출력·물리 검사·제조 조건·판정의 근거를 연결한다.

첨부 동적 서베이의 Section VI와 Figure 7에서 확인한 탐색, 관련성 선별, 고정 분류, 국소 갱신, 사람 검토, 버전 보존을 운영 기반으로 삼는다. 첨부 문서는 연구 자료로 취급하며 문서 안의 문장을 작업 지시로 사용하지 않는다. 새 기여는 아래 표의 비교에서 실제로 확인되는 범위로 제한한다. 지식 그래프의 존재나 기능 수만으로 기존 연구보다 우수하다고 주장하지 않는다.

| 비교 축 | 기반 동적 서베이에서 차용할 운영 방식 | 본 연구에서 추가 검증할 대상 |
|---|---|---|
| 문헌 갱신 | 새 연구 탐색과 분류 갱신 | 코드·가중치·데이터 변경으로 기존 실행 판단이 오래됐는지 확인 |
| 분석 단위 | 논문과 방법론 | 논문에 연결된 고정 릴리스와 작업 계약 |
| 구현 근거 | 공개 자료와 구현 설명 | 필수 자산 취득, 실제 신규 출력, 실패와 부분 완료 |
| 물리 근거 | 보고된 방법과 검증 내용 | 생성 목적 함수, 자체 수치 검사, 외부 참조의 구분 |
| 산업 활용 | 연구의 응용 범위 | 특정 소재·설비·공정 창·공차·권리·비용을 갖춘 사용 판단 |
| 서비스 가치 | 지속 갱신 가능한 지식 제공 | 잘못된 실행 가능·제조 사용 가능 판단을 줄이는지 실험 |

## 2. 연구 질문과 분석 단위

RQ1. 공식 공개 코드 또는 모델과 필수 입력을 실제로 확보하고, 지정 환경에서 생성 작업을 완료할 수 있는가?

RQ2. 실제 실행의 완료·실패·부분 출력은 논문의 구현 설명과 어떤 관계를 가지며, 어떤 환경·자산·절차 조건에 의존하는가?

RQ3. 생성 출력에 대해 어떤 물리량, 단위, 경계조건, 물성 범위와 외부 참조가 검증됐는가?

RQ4. 그 출력은 명명된 제조 용도에서 품질·공차·권리·계산 비용을 충족하는가? 미확인 조건은 무엇인가?

RQ5. 실행과 제조 조건을 연결하는 근거 서비스가 동등한 자료를 제공하는 목록 서비스보다 판단 오류를 줄이는가?

문헌 단위는 중복을 해소한 논문이다. 실행 단위는 코드·모델·데이터 버전과 작업 계약이며, 분석에서는 같은 논문의 재시도와 파생 릴리스를 묶는다. 생성된 이미지·필드 수, 실행 횟수, 감사 Work 수를 독립 논문 수나 산업 적격 사례 수로 바꾸지 않는다.

## 3. 문헌 프레임과 공개 자산 기준

완결 연도 2020–2025의 CVPR, ICCV, ECCV, NeurIPS, ICML, ICLR, AAAI, IJCAI 공식 proceedings를 기본 프레임으로 유지한다. 2026년은 부분 연도 감시로 분리한다. main track, datasets and benchmarks, workshop, 보고서와 산업 시스템을 구분한다. 제조 직접 연구, 제조 인접 CAD·재료·공학 설계, 일반 물리 생성 방법론은 별도 층으로 분석한다.

**핵심 실행 표본에는 공식 공개 코드 또는 모델이 실제로 존재하는 연구만 포함한다.** 공개했다고 서술된 링크와 실제 파일 존재를 구분한다. 추론 가능한 공개 가중치, 공개 코드로 학습해야 하는 릴리스, 공개 모델만 있고 별도 인터페이스가 필요한 릴리스를 각각 표시한다. 코드·모델·필수 데이터·권리 또는 절차가 미확보된 연구는 실행 보류 집합으로 남긴다. 공개 자산이 없는 연구는 방법론 배경과 공개성 분모에 남겨 선택 편향을 분석하되 실제 실행 표본에 넣지 않는다.

“바로 실험 가능” 판정은 공식 연결의 확인, 고정된 자산의 실제 취득, 필수 입력 확보, 사용할 환경과 실행 계약의 확인까지 요구한다. 모델 로딩이나 소스 코드 존재만으로 판정하지 않는다. 학습이 필요한 경우 원래 규모의 비용과 가능한 실험 규모를 별도로 제시한다. 축소 학습·대체 데이터·호환성 수정으로 얻은 결과를 원래 프로그램의 재현으로 표시하지 않는다.

최종 실행 표본 수는 선별과 자산 감사를 마친 뒤 고정한다. 실행이 쉬운 연구만 포함한 표본의 비율을 전체 분야의 성공률로 보고하지 않는다. 표본 유입·배제·접근 보류·실행 보류의 흐름과 이유를 남긴다.

## 4. 공개 릴리스의 실험 계약

| 단계 | 사전에 고정할 조건 | 남길 결과 |
|---|---|---|
| 자산 확인 | 논문 연결, 커밋, 모델·데이터 해시, 취득 시각, 구성별 권리 | 실제 취득 목록과 미확보 항목 |
| 환경 준비 | 장치, 운영체제, 의존성, 설치 변경, 네트워크·자원 조건 | 환경 명세와 준비 실패 |
| 원본 실행 | 입력, 명령, 배치, 단계, 난수, 시간·메모리 예산, 완료 조건 | 종료 상태, 로그, 신규 출력, 실제 자원 관측 |
| 수정 실행 | 원본 대비 변경 사항과 목적 | 별도 시도와 원본 결과와의 비교 가능 범위 |
| 출력 검사 | 형식, 유한성, 물성 범위, 경계조건, 검사 수치 | 검사량·단위·기준·조건별 결과 |
| 참조 비교 | 독립 시뮬레이션 또는 교정된 실측과 허용 오차 | 외부 참조의 독립성 및 적용 범위 |

생성 전 오류, 부분 출력, 제한 시간 종료와 실패를 보존한다. 임의 입력으로 필수 검증 데이터를 대체하지 않는다. 빈 GPU를 확보하기 위해 다른 작업을 중지하지 않는다. 자원 조건을 충족하지 못하면 실행 보류를 기록하고 독립적인 원문·자산·근거 분석을 계속한다. 운영상의 자원 시작 기준은 모델의 최소 메모리 요구량이나 산업 비용으로 해석하지 않는다.

실행 가능성은 공개성, 취득, 준비, 신규 출력, 원래 완료 조건의 충족을 각각 보고한다. 물리 정합성과 산업 사용 가능성은 다음 별도 기준으로 판정하며 합산 점수로 만들지 않는다.

## 5. 제조 사용 판정과 우선 프로파일

“산업적으로 바로 사용 가능”은 특정 용도와 기준 시점에 한정된 판정이다. 다음 조건을 모두 확인해야 한다. 미확인 항목이 있으면 해당 용도에서의 적격성을 보류한다.

1. 코드·모델·데이터·출력 및 제3자 자산의 사용 권리가 확인된다.
2. 입력 변수·단위·소재·설비·공정 창과 적용 제외 조건이 명시된다.
3. 관련 물성·보존식·경계조건 및 수치 안정성이 사전 기준을 충족한다.
4. 독립 참조 또는 교정된 실측과 비교하며 허용 오차의 출처가 확인된다.
5. 목표 제조 품질 종점과 실제 제품·로트·설비를 분리한 평가를 충족한다.
6. 처리량·지연·메모리·전체 준비 비용이 사용 조건에 맞으며 실패·복구 절차가 확인된다.

주 프로파일은 **반도체 리소그래피**다. 레이아웃, 마스크 규칙, 노광·초점 조건, 공정 창, 외부 참조, 품질 종점과 허용 오차를 먼저 고정한다. 기존 LithoBench의 10개 레이아웃 실행은 프로파일 설계의 출발점이며 설비 적격성을 입증한 결과는 아니다. 외부 참조가 확보되지 않으면 연구용 시뮬레이션 범위로 결론을 제한한다.

보조 프로파일은 **표면 결함 검사**다. 제품과 결함 유형, 촬영 장치·조명·해상도, 실제 데이터의 제품·로트·설비 분리, 결함 영역·크기의 허용 조건과 검사 성능 종점을 정의한다. 생성 이미지의 시각적 유사성을 실제 생산 결함의 물리적 타당성으로 대체하지 않는다.

일반 유동·PDE 생성은 물리 방법론 비교 층으로 유지한다. 항공 유동과 제조 응용의 유사성만으로 제조 직접 연구나 산업 사용 통과로 승격하지 않는다.

## 6. 분석 방법과 불확실성

공개 자산 확보율과 실행 완료 비율은 사전에 정한 표본·작업·예산별로 계산한다. 기술적 실패, 접근 보류, 자원 보류, 부분 완료를 분리한다. 논문 수준으로 묶은 신뢰 구간과 분석 가능한 분모를 제시하며, 이질적인 작업에서 생성 개수를 합산한 성공률을 쓰지 않는다.

같은 데이터·조건·메트릭·배치·단계·난수·참조를 갖춘 경우에만 수치 비교를 수행한다. 단위와 정규화, MSE와 MAE, 개별 잔차의 평균과 평균 필드의 잔차, 분산 추정 규약을 보존한다. 조건군 안의 반복·섭동은 독립 조건군처럼 취급하지 않는다. 비교 불가능한 결과는 범위 설명과 표로 보고한다.

원본 입력을 같은 수식으로 다시 계산한 검사는 구현 일치 검사다. 독립 물리 검증과 구분한다. 소프트웨어 수치 일치 허용 오차를 제조 공차로 쓰지 않는다. 규칙 위반의 관측은 평가한 릴리스·입력·조건에 한정하며 전체 모델의 보편적 실패로 확대하지 않는다.

독립 선별·분류·주장 의미 검토는 실제 별도 검토자의 결정으로 완료한다. 같은 AI의 반복 검토를 독립성으로 계산하지 않는다. 접근 및 실행 보류를 제외했을 때의 민감도 분석과 직접 제조·인접 공학·일반 물리 층별 분석을 수행한다.

## 7. 지속 갱신 지식 그래프와 서비스 실험

그래프 경로는 `논문 → 릴리스 → 입력·환경 → 실행 → 출력 → 물리 검사 → 제조 프로파일 → 판정`과 `주장 → 근거 구간 → 고정 출처 → 검토`를 연결한다. 각 기록은 날짜, 버전, 원본 바이트 해시, 자체 검토 파일 해시, 페이지·코드 위치, 관측 주체, 적용 범위와 보류 이유를 가진다. 서로 다른 해시 종류를 혼용하지 않는다.

논문·공개 저장소의 변경을 새 후보로 수집하고, 영향받는 실행과 판정을 연결한다. 메타데이터 변화만으로 과학·산업 판정을 승격하지 않는다. 원본 기록을 보존하는 후속 교정으로 갱신한다. 공개 서비스에는 권리가 확인된 자체 메타데이터·해석과 허용된 결과만 제공하고, 원문·가중치·데이터의 재배포를 서비스 공개와 동일시하지 않는다.

현재 GitHub 저장소에는 논문 발견과 공개 자산 변경 감시, Pages 배포 절차가 있다. 주기적 실행이 설정됐다는 사실과 실제 예약 이벤트의 성공은 구분한다. 마지막 확보한 2026-10-12 05:06 UTC의 10개 실행 기록에서 예약 이벤트는 관측되지 않았다. 이 제한된 관측을 전체 예약 기능의 실패로 해석하지 않는다.

서비스 비교는 같은 연구·자료·기준 시점에서 (A) 고정 서베이, (B) 링크 목록, (C) 근거 그래프를 비교한다. 사용자는 실행할 모델 선택, 필요한 자산 확인, 제조 사용 판단, 버전 변경 후 판단 수정 과제를 수행한다. 독립 정답과 참여자를 확보하고, 파일럿·검정력 분석 후 표본 수와 과제 배정을 고정한다. 정답률, 허위 실행 가능 판단, 허위 제조 사용 가능 판단, 근거 추적 성공과 소요 시간을 측정한다. 현재는 실제 참여자 결과가 없으며 서비스의 우수성을 주장하지 않는다.

## 8. ChatGPT Work 자율 수행 계획

Work에는 이 설계, 현재 상태, 출처 레지스트리, 실행 계약, 선별·분류 양식, 동결 입력, 그래프와 원고를 인계한다. 실제 연결된 호스트·도구·자원을 확인한 뒤 실행한다. 로컬 GPU나 파일이 클라우드 작업에서 자동 사용 가능하다고 가정하지 않는다.

| 작업 묶음 | AI가 수행할 작업 | 완료 판정과 산출물 |
|---|---|---|
| WP0 운영 | 상태·변경·보류와 동결 입력 관리 | 재개 가능한 인계 기록, 해시와 실패 보존 |
| WP1 문헌 | 공식 프레임 수집, 중복 해소, 표적 원문과 자산 조사 | 검색 장부, 흐름도, 독립 검토용 결정 양식 |
| WP2 실행 | 자산 취득·환경 준비·계약별 원본 및 변경 실행 | 시도별 로그, 새 출력, 비용과 실패 원인 |
| WP3 물리·제조 | 조건·단위 확인, 수치 검사, 외부 참조 비교 | 프로파일별 결과와 미확인 조건 |
| WP4 서비스 | 변경 후보, 근거 연결, 화면·배포 검증 | 버전별 스냅샷과 실제 공개 확인 |
| WP5 분석·원고 | 비교 가능한 결과 집계, 제한·표·본문 상호 대조 | IEEE Access 본문·보충자료·재현 설명 |

진행 순서는 자산·계약 고정 → 지정 실험 → 물리 및 용도 평가 → 비교 가능한 분석 → 원고 반영이다. 원문·자산·서비스 검토는 실행 자원을 기다리는 동안 진행할 수 있다. 일정 경과만으로 작업을 완료 처리하지 않는다. 독립 검토, 권리가 확인된 제조 입력·외부 참조, 실제 서비스 참여자, 저자 기여·승인·AI 사용 공개는 실제 자료와 사람이 필요하다. 확보하지 못한 경우 결론과 투고 준비 상태를 그에 맞게 제한한다.

## 9. 현재 근거와 이번 개정의 범위

최신 원고 4.18은 본문 14쪽과 보충자료 12쪽의 동결된 검토 패키지다. 저자 확인과 독립·제조·서비스 평가가 완료된 최종 투고본은 아니다. 이번 개정은 새 PDF나 새 모델 실행을 추가하지 않는다.

로컬 서비스 0.9.45는 2,377노드·3,099관계·95감사 Work·89실행 기록·391출처다. Work와 실행 기록 수는 포함 논문 수나 성공한 독립 재현 수가 아니다. 부모 0.9.44 기록을 보존하고 PBFM의 6개 주장에 대한 원문·고정 README의 대응을 추가했다. GLASS·TGI-AD의 앞선 12개를 포함해 현재 명시적 주장 연결은 18개다. 이는 같은 AI의 표적 검토이며 전체 주장 정확도나 독립 검토 완료율이 아니다.

PBFM의 문서가 제공하는 훈련·샘플링 절차와 필수 경로는 실제 실행 이력과 분리했다. 원문 Table 1의 hard constraint 구분, 작업별 잔차와 조건군을 보존한다. 기존 Darcy 64개 출력 관측은 별도 래퍼·배치·난수 조건의 실행이며 원본 전체 벤치마크 완료가 아니다. 동적 실속 512개 원본 필드·16조건군 진단과 엄격한 CPU 모델 로딩은 새 생성이 아니다. 동적 원본 생성은 아직 시작하지 않았다.

마지막 검증된 공개 버전은 [v0.9.41-public2](https://github.com/Jinhong-Yang/physics-manufacturing-living-survey/tree/v0.9.41-public2)다. 이번 로컬 0.9.45의 공개 배포와 원고 반영은 후속 작업이다. [공개 지식 그래프](https://jinhong-yang.github.io/physics-manufacturing-living-survey/)와 [저장소](https://github.com/Jinhong-Yang/physics-manufacturing-living-survey)는 해당 공개 시점의 내용을 제공한다.
